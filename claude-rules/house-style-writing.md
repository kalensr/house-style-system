# Human-Facing Writing

For human-facing prose, invoke `/house-style` before drafting, revising, or
reviewing. Use the active project's `HOUSE_STYLE.md` when it exists. Apply the
skill's Spoken-Voice and Anti-Cadence Rules. Preserve facts and evidence
limits. Preserve necessary uncertainty. Leave quoted text and code unchanged.
Keep citations and required legal language exact.

Run the Natural Voice and Sloganized Synthesis pass before finalizing the
draft. Resolve every nominated passage as revised, retained with reason, or
protected source. A disposition applies only to the exact passage reviewed.

Run a project style gate only after editing a deliverable and before handoff
when the project provides one. State plainly when the gate did not run.
