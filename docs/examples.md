# Examples

Use these examples as patterns for review and revision.

## Contrast Scaffolding

Before:

```text
A checklist can remind me to separate facts from assumptions. It cannot do the thinking for me.
```

After:

```text
A checklist owns repeatable prompts. The writer owns the thinking.
```

## Negation-First Framing

Before:

```text
The value is not arriving with a borrowed playbook. It is recognizing a useful pattern from another setting.
```

After:

```text
Experience across settings helps a leader recognize a useful pattern and test whether it fits the current organization.
```

## Question Cadence

Before:

```text
Where does the information come from? Who makes the decision? Which system handles the repeatable work?
```

After:

```text
Leaders need a clear picture of the information entering the process, the people responsible for decisions, and the systems handling repeatable steps.
```

## Concrete Subjects

Before:

```text
The work can stay connected to both sides of the problem.
```

After:

```text
Technology leaders can work with executives setting direction and teams responsible for delivery.
```

## Career Scope

Before:

```text
Fractional technology leadership is where I focus.
```

After:

```text
I am drawn to technology leadership roles where I can work with executives on direction and with technology teams on delivery.
```

## Generic Closing

Before:

```text
This framework paves the way for a brighter future of writing.
```

After:

```text
This framework gives reviewers a place to start.
```

## Weak Evidence

Before:

```text
AI writing is usually worse because it sounds generic.
```

After:

```text
AI-assisted drafts often need review for generic tone, weak evidence, and missing author judgment.
```

## Filler

Before:

```text
It is important to note that the system should be used thoughtfully.
```

After:

```text
Use the system thoughtfully.
```

## Human Review Boundary

Before:

```text
The style gate proves the document is ready.
```

After:

```text
The style gate shows the document avoided known style risks. Human review still owns truth, evidence, and recommendation quality.
```
